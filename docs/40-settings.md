# 影像分析設定

影像分析決定系統要對攝影機畫面執行哪些偵測。這一章說明怎麼開啟人臉辨識。

## 操作步驟

1. 點擊畫面上方的「系統設定」分頁。
2. 在「影像分析」區塊，開啟「{{legend.face}}」。

{{screenshot:settings-01}}

3. 點擊頁面下方的「儲存設定」。

## 完成後

畫面出現「設定已儲存」的通知，表示設定已經保存。

「{{legend.face}}」開啟後，下方會出現「{{legend.threshold}}」，預設值為 75%。

「{{legend.motion}}」預設就是開啟的，不需要另外設定。

> 注意：「{{legend.threshold}}」只有在「{{legend.face}}」開啟時才會顯示。
