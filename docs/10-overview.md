# 介面總覽

開啟 DemoStreamApp 後，預設會進入「即時監控」分頁。這一章說明畫面上三個主要區域的位置與用途。

## 操作步驟

1. 等待左側的「攝影機清單」載入完成。

{{screenshot:overview-01}}

## 完成後

畫面分成三個區域：

- 「{{legend.stats}}」：顯示「線上攝影機」、「待處理告警」與「推論 FPS」。
- 「{{legend.cameras}}」：列出所有攝影機，可以搜尋名稱或位置，也可以點擊「新增攝影機」。
- 「{{legend.grid}}」：顯示攝影機的即時畫面，上方可以切換「版面」與套用「版面設定」。

在「{{legend.cameras}}」雙擊一台攝影機，它的即時畫面就會依序填入「{{legend.grid}}」的空格，詳見「即時監控畫面」一章。
