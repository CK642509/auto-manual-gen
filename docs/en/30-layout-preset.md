# Saving a Layout

Save the current layout and its cell assignments as a named layout, so you can restore it later from the **Saved layout** drop-down in one step.

## Steps

1. Wait for the **Cameras** list on the left to finish loading.
2. Double-click **Gate-A**. Its live view fills the first empty cell on the right, shown as **{{legend.cell}}** in the figure.

{{screenshot:layout-preset-01}}

3. Under **Layout** at the top, click **4×4**.
4. Click **Save Layout**.
5. In **{{legend.name}}**, type **Lobby Patrol**.

{{screenshot:layout-preset-02}}

6. Click **{{legend.confirm}}**.

## Result

The notification **Layout "Lobby Patrol" saved** appears, which means the layout has been saved.

To restore it later, select **Lobby Patrol** from the **Saved layout** drop-down. The layout and its cell assignments are applied again. Before saving, check the **{{legend.summary}}** at the top of the dialog to confirm the layout and the number of assigned cells.

> Note: With a layout of **3×3** or larger, the **{{legend.fps}}** is not shown at the bottom of each cell.
