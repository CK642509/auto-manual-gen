# 儲存版面設定

把目前的版面與格子配置存成一組版面設定，之後可以從「版面設定」下拉選單一次套回來。

## 操作步驟

1. 等待左側的「攝影機清單」載入完成。
2. 雙擊「Gate-A」。它的即時畫面會填入右側第一個空格，也就是圖中的「{{legend.cell}}」。

{{screenshot:layout-preset-01}}

3. 在上方的「版面」點擊「4×4」。
4. 點擊「儲存版面」。
5. 在「{{legend.name}}」輸入「大廳巡檢」。

{{screenshot:layout-preset-02}}

6. 點擊「{{legend.confirm}}」。

## 完成後

畫面出現「版面設定『大廳巡檢』已儲存」的通知，表示版面設定已經保存。

之後在「版面設定」下拉選單選擇「大廳巡檢」，就會套回這個版面與格子配置。儲存前，可以先看對話框上方的「{{legend.summary}}」，確認版面與已配置的格數是不是你要的。

> 注意：版面切換到「3×3」以上時，格子底部不會顯示「{{legend.fps}}」。
