# 即時監控畫面

即時監控是開啟 DemoStreamApp 後的預設畫面。這一章說明怎麼找到一台攝影機，並把它的即時畫面放進右側的版面。

## 操作步驟

1. 等待左側的「攝影機清單」載入完成。

{{screenshot:live-monitor-01}}

2. 在「{{legend.search}}」輸入「lobby」。
3. 在篩選後的清單中，雙擊「Lobby-01」。

{{screenshot:live-monitor-02}}

## 完成後

「Lobby-01」的即時畫面會填入右側第一個空格，也就是圖中的「{{legend.cell}}」，畫面右下角同時會出現「Lobby-01 已加入格 1」的通知。

要換掉某一格的攝影機，點擊該格右上角的「{{legend.remove}}」，其他格子不受影響。要改變格子數量，使用上方的「{{legend.layout}}」；要把目前的配置存起來，點擊「{{legend.save}}」，詳見「儲存版面設定」一章。

> 注意：雙擊會依序填入第一個空格。版面已滿時會出現「版面已滿，請先移除某一格或改用更大的版面」，這時先移除某一格，或改用更大的版面。
