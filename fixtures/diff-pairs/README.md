# diff-pairs —— 已知答案的圖對

對應系列 **Day 22**（讓 AI 判斷這次的差異合不合理）。

拿來檢驗「AI 差異判讀」到底靠不靠譜。每一組是 `before.png` / `after.png` / `expected.md`。

| 目錄 | 內容 | 期望的判定 |
|---|---|---|
| `injected-bugs/` | 刻意注入的問題：欄位消失、標號錯位、渲染失敗、遮罩落空 | `broken` 或 `suspicious` |
| `normal-changes/` | 正常改版：配色調整、文案微調、間距變化 | `expected` |

## 誠實的界線

樣本量小，這是**示範判讀品質長什麼樣**，
**不是**量測偽陽／偽陰率。要用在自己的專案，就得自己擴充樣本、自己建立信心。

真正帶得走的東西是歸納出來的兩份清單：**AI 判得好的類型** 與 **判不準的類型**。
